# World Crokinole Rankings — Пользователи и роли (русский)

Описание **как люди пользуются продуктом**, **кто что может делать**, и чем **события**, **турниры** и **клубы** отличаются. Для продуктовой команды и UX, без технических деталей реализации.

---

## 1. Кто пользуется сайтом

| Аудитория | Типичные цели |
|-----------|----------------|
| **Гость (не вошёл)** | Смотреть рейтинги, события, игроков, клубы; часто ведётся к регистрации / онбордингу. |
| **Игрок (аккаунт)** | Личная статистика, запись на события, профиль и подписка, клубы, при желании — организация активностей. |
| **Организатор события / турнира** | Создаёт карточки, регистрации, сетку; для **ранжируемых** турниров вносит результаты, влияющие на рейтинг. |
| **Владелец или админ клуба** | Страница клуба, заявки, приглашения, бонусы (например промокоды). |
| **Оператор площадки** | Отдельная **админ-панель** для глобального управления данными (см. роли ниже). |

## 2. Роли и права (что приложение различает)

В продукте одновременно участвуют **тариф подписки**, **роль в клубе**, **автор события** и отдельный флаг **админа сайта**.

### 2.1 Тарифы подписки (`standard`, `premium`, `administrator`)

Отображаются в шапке и задают возможности **организатора**:

- **Standard (бесплатно)**  
  - Можно создать **простое событие** с жёсткими ограничениями: **только неранжируемое**, **без платного входа** (только бесплатно), **не больше одного «активного» события** на аккаунт (пока оно не закончится — второе не создать).  
  - В блоке событий **нет** кнопки **«Create Ranked Tournament»** — она для **Community Administrator** (см. ниже).  
  - По-прежнему можно **смотреть каталог**, **регистрироваться** на чужие события/турниры и **платить**, если у события есть цена.

- **Premium**  
  - **Простое событие** без ограничений бесплатного плана (ранжируемость и цена — по правилам формы).  
  - В hero событий видна **«Create New Event»** (если условия выполнены).  
  - Участие в событиях и клубах — как у любого вошедшего пользователя.

- **Administrator** (в интерфейсе это уровень вроде **Community Administrator** — платный тариф, **не** то же самое, что «админ сайта»)  
  - Всё, что Premium для создания событий, **плюс** в hero событий кнопка **«Create Ranked Tournament»** как главный вход в турнирный мастер.  
  - В hero клубов — **создать клуб** или перейти в **«мой клуб»**, если пользователь уже админит клуб.  
  - На профиле показывается блок в духе **«мои клубы»** для этого тарифа.

Оплата Premium / Community Administrator — через **Stripe**; отмена/управление — в профиле, где предусмотрено.

### 2.2 Оператор сайта (`is_admin` в профиле)

- **Отдельно** от подписки.  
- Только с этим флагом доступна **`/admin`** (панель: события, игроки, клубы, новости, история матчей, рейтинги, профили, подписки и т.д.).  
- Это **сотрудник / суперпользователь**, а не «я провожу турнир в городе».
- Отдельного флага/роли `superadmin` в текущей версии нет: фактически «суперпользователь сайта» = пользователь с `profiles.is_admin = true`.
- Как назначить через Supabase:
  - открыть таблицу `profiles`, найти строку пользователя по `id` (это UUID из `auth.users`);
  - выставить `is_admin = true` и сохранить;
  - при необходимости снять доступ: `is_admin = false`.
- Практически удобнее делать SQL:
  - `update profiles set is_admin = true where id = '<auth_user_uuid>';`
- После назначения/снятия доступа пользователю лучше перелогиниться, чтобы права в интерфейсе обновились.

### 2.3 Роли в клубе

- **Участник** — в списке клуба, пользуется бонусами (например копирует код скидки), может **выйти из клуба**.  
- **Админ клуба** — редактирует клуб, **заявки на вступление**, **приглашения**, **скидки**, доступ участников через попапы.  
- **Владелец** — админ с правом **удалить клуб**; прочие админы могут уйти из роли без удаления клуба.

### 2.4 Роли у события / турнира

- **Организатор (создатель)** — аккаунт, создавший карточку: правки (где UI позволяет), **статус турнира** (черновик / live / public), страница **ввода результатов** для ранжируемых турниров.  
- **Участник** — регистрация (бесплатно или оплата), при настройке — выбор **квалификационного heat**, при необходимости отказ от участия через UI.

## 3. Сценарии (сквозные)

### 3.1 Первый визит и аккаунт

- С «домашней» страницы локали **гостей** обычно направляют в поток **new-visitor** (шаги + save-continue), а не на основной «дашборд».  
- **Вошедшие** попадают на **дашборд** — главный хаб: hero, новости, превью рейтингов, события, клубы, апгрейд подписки.

### 3.2 Просмотр без организации

Блок **навигации** ведёт в четыре направления:

- **Рейтинги** — общие списки (лавры / одиночки / пары в терминах экрана).  
- **События** — каталог и карточка события.  
- **Игроки** — поиск и фильтры, **публичный профиль** (рейтинги, история, бейджи).  
- **Клубы** — список и страница клуба.

### 3.3 Запись на событие или турнир

- Нужен **вход в аккаунт**.  
- **Бесплатно** — регистрация в один-два шага (после выбора heat, если турнир с квалификацией).  
- **Платно** — оплата через **Stripe** из попапа.  
- При лимите мест интерфейс показывает заполненность, если данные есть.

### 3.4 Простое **событие** и **турнир**

| | **Простое событие** («Create New Event») | **Турнир** (мастер) |
|---|------------------------------------------|---------------------|
| **Зачем** | Встречи, локальные игры, проще по полям. | Соревнование: этапы, посев, сетка, опционально квалы. |
| **Создание** | Короткая форма. | Несколько шагов (детали, структура, видимость). |
| **Ранжируемость** | Premium+ по форме; **бесплатный план только unranked**. | Шаг **ranked / unranked**; ranked влияет на **рейтинг**. |
| **Видимость** | Обычная карточка, у организатора **Edit**. | **Черновик** скрыт от чужих, пока организатор не выставит **live/public**; свой черновик видит только создатель. |
| **После проведения** | По задумке UI. | Организатор заходит на **страницу результатов**: вносит матчи; **только создатель**; ranked обновляет рейтинги и таблицы. |

**Замечание:** Кнопка **«Create Ranked Tournament»** в интерфейсе рассчитана на подписчиков **Community Administrator**, но URL мастера турнира в коде закрыт только **авторизацией** — продуктовая политика может потребовать доп. проверку на сервере.

### 3.5 Рейтинги с точки зрения игрока

- **Ранжируемые** матчи турнира меняют **рейтинг (Elo-логика)** в одиночках или парах.  
- **Таблицы лидеров** обновляются после сохранения результатов.  
- **Лавры** и **тренд** на экране рейтингов — часть соревновательной картины.  
- На хабе показывается **превью «моих»** показателей, если профиль связан с записью игрока.

### 3.6 Клубы — вступление и управление

**Открытый клуб** (не «только по приглашению»):

- Без входа: **Join Club** → на **регистрацию**.  
- С входом: заявка → статус **на рассмотрении**, пока админ не **одобрит** / **отклонит**.  
- Админ может **пригласить**; у приглашённого **Принять / Отклонить**.

**Только по приглашению** (`locked`):

- Не-админы видят **Invite only** — без кнопки открытой заявки.

**Создание клуба:**

- В hero клубов кнопка **Create Club** (или переход в свой клуб) только у **Community Administrator**. Создатель становится **владельцем/админом**.

**Внутри клуба:**

- **Админы:** правки, заявки, приглашения, скидки, контакты.  
- **Участники:** состав (с колонками рейтингов при наличии данных), бонусы, выход.

### 3.7 Привязка истории к аккаунту (claim)

- Поток **claim history** помогает привязать **исторические записи матчей** к логину, чтобы профиль отражал прошлое.  
- Это не то же самое, что ежедневный ввод результатов турнира (только организатор).

### 3.8 Профиль и подписка

- **Профиль:** аккаунт, **подписка**, таблица турниров, бейджи рейтинга/матчей, **созданные события**, **клубы** (расширенно для Community Admin).  
- **Тарифы** — сравнение планов и переход в оплату.

### 3.9 Уведомления

- **В шапке** — вход к in-app уведомлениям (приглашения в клуб, исход заявок и т.п.).

### 3.10 What’s News в админке

- Контент блока **What’s News** на главной/дашборде управляется из админки в секции `news`.
- Внутри `/admin` для `news` кнопки Add/Edit ведут на отдельные страницы формы:
  - `/{locale}/admin/news/new` — создать новость;
  - `/{locale}/admin/news/{id}/edit` — редактировать существующую.
- Поля карточки:
  - `image` (картинка),
  - `title`,
  - `description` (rich text),
  - `link_text` (текст кнопки),
  - `sort_order` (порядок сортировки),
  - `created_at` (дата публикации).
- Картинка грузится в Supabase Storage (`news-images`), а в `news.image` сохраняется публичный URL.
- Как это работает для пользователя на сайте:
  - на главной/дашборде блок называется **What’s New** и показывает карточки новостей;
  - карточки выводятся с пагинацией по 3 на страницу;
  - порядок карточек задаётся админом через `sort_order` (при равенстве новее запись выше);
  - клик по кнопке/карточке открывает отдельную страницу новости `/news/{id}` с полным текстом и датой.

## 4. Шпаргалка: «Могу ли я …?»

| Действие | Гость | Standard | Premium | Community Admin (`subscription administrator`) | Сайт `is_admin` |
|----------|-------|----------|---------|--------------------------------------------------|-----------------|
| Смотреть рейтинги / игроков / публичные события | Да (где открыто) | Да | Да | Да | Да |
| Регистрация / оплата событий | Нет (нужен вход) | Да | Да | Да | Да |
| Создать простое событие | Нет | Да (1 активное, unranked, бесплатно) | Да (по форме) | Да | — |
| Кнопка hero «Create Ranked Tournament» | Нет | Нет | Нет | Да | — |
| Создать клуб (hero) | Нет | Нет | Нет | Да | — |
| Панель `/admin` | Нет | Нет | Нет | Нет | Только да |
| Внести результаты ranked-турнира | Нет | Только если **ты** создатель | То же | То же | То же |
| Одобрять заявки в клуб | Нет | Если админ клуба | Если админ клуба | Если админ клуба | — |

## 5. Глоссарий

- **Событие (event)** — общая карточка; не обязательно турнир; короткий флоу создания.  
- **Турнир (tournament)** — формат Tournament: сетка, опционально heats, черновик/live, структура этапов.  
- **Ranked (ранжируемый)** — результаты влияют на **рейтинг** и **обновление таблиц**.  
- **Unranked** — может быть регистрация и сетка, но без цепочки влияния на рейтинг как у ranked.  
- **Community Administrator** — **тариф** в UI (клуб + турнирная CTA); **не** «админ сайта».  
- **Админ сайта** — флаг `is_admin` для панели `/admin`.
